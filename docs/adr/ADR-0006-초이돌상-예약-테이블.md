# ADR-0006: 초이돌상 예약 테이블

- 날짜: 2026-11-24
- 상태: 제안
- 작성자: 팀

## 배경 (Context)

초이돌상 예약은 항상 고객 문의에서 시작한다. 운영자가 문의 상세에서 예약 진행을 누르면 예약 폼이 열리고,
문의에 적힌 값으로 기본값이 채워진 상태에서 예약을 확정한다. 예약은 예약중 → 취소환불 또는 완료로 끝나며,
완료한 예약은 나중에 매출 집계에 쓰인다.

## 결정 (Decision)

1. `choidolsang.reservations` 테이블을 만든다.

   | 컬럼              | 타입                  | 필수 | 설명 |
   | ----------------- | --------------------- | ---- | ---- |
   | `id`              | UUID                  | ✓    | 내부 식별자 |
   | `code`            | VARCHAR(16), UNIQUE   | ✓    | 예약 번호. 예약을 만든 문의의 문의 번호와 같다 |
   | `inquiryId`       | UUID (FK), UNIQUE     | ✓    | 예약을 만든 문의. 문의 하나에 예약 하나 |
   | `customerName`    | VARCHAR(100)          | ✓    | 예약자 성함 |
   | `customerPhone`   | VARCHAR(20)           | ✓    | 예약자 연락처. 하이픈 없이 숫자만 (`0`으로 시작 9~11자리) |
   | `eventAt`         | TIMESTAMPTZ           | ✓    | 행사 날짜·시간 |
   | `eventLocation`   | VARCHAR(200)          | ✓    | 행사 장소 |
   | `babyName`        | VARCHAR(100)          | ✓    | 아기 이름 |
   | `babyGender`      | `baby_gender`         | ✓    | `boy`(남아) / `girl`(여아). 폼 기본값 남아 |
   | `conceptId`       | UUID (FK)             | ✓    | 돌상 컨셉 |
   | `guestCount`      | INTEGER               | ✓    | 참석 인원 (1명 이상) |
   | `hasSnap`         | BOOLEAN               | ✓    | 스냅 촬영 포함/미포함. 폼 기본값 미포함 |
   | `requests`        | TEXT                  |      | 추가 요청 사항 (최대 2000자) |
   | `extraComponents` | TEXT[]                | ✓    | 추가 요청 구성품 목록 (최대 50개, 각 200자) |
   | `totalAmount`     | INTEGER               | ✓    | 최종 결제 금액 (원) |
   | `depositAmount`   | INTEGER               | ✓    | 예약금 (원), 기본 50,000 |
   | `confirmedOn`     | DATE                  | ✓    | 예약 확정 날짜 |
   | `status`          | `reservation_status`  | ✓    | `reserved`(예약중) / `cancelled`(취소환불) / `completed`(완료) |
   | `cancelledAt`     | TIMESTAMPTZ           |      | 취소환불 처리 시각 |
   | `completedAt`     | TIMESTAMPTZ           |      | 업무 완료 시각. 매출 집계 기준 |
   | `createdAt`, `updatedAt` | TIMESTAMPTZ    | ✓    | |

   - 잔금은 저장하지 않고 `totalAmount - depositAmount`로 계산해 응답에 싣는다. 예약금은 최종 결제 금액보다 클 수 없다.
   - 금액은 기록용 숫자다. 실제 결제·환불 처리는 하지 않는다.
2. 문의와 예약의 상태를 함께 바꾼다.

   | 동작 | 예약 | 문의 |
   | ---- | ---- | ---- |
   | 예약 확정(생성) | `reserved` | `pending`·`rejected` → `confirmed` (거절 사유 삭제) |
   | 예약 취소 | `reserved` → `cancelled` | → `cancelled` |
   | 업무 완료 | `reserved` → `completed` | 그대로 `confirmed` |

   - 예약 생성은 한 트랜잭션에서 문의 행을 잠그고(`FOR UPDATE`) 상태를 확인한 뒤 처리한다.
     `inquiryId` UNIQUE 제약으로 같은 문의의 두 번째 예약은 409.
   - 취소·완료는 `reserved`일 때만 조건부로 갱신한다. 이미 처리된 예약은 409.
   - 문의를 추가할 때 고를 수 있는 상태는 대기·거절뿐이다. 예약확정·취소는 예약으로만 바뀐다.
   - 예약으로 이어진 문의는 숨김 삭제할 수 없다(409).
   - 예약 폼의 돌상 컨셉은 숨김 삭제되지 않은 것만 고를 수 있다(아니면 400).
3. API (모두 초이돌상 관리자 세션 필수)
   - `GET /admin/choidolsang/reservations?page=` — 목록 20건씩, 행사 일시 늦은 순
   - `GET /admin/choidolsang/reservations/:code` — 상세 (문의 번호, 컨셉, 잔금 포함)
   - `POST /admin/choidolsang/reservations` — 문의에서 예약 생성 `{ inquiryCode, customerName, eventAt, … }`
   - `PATCH /admin/choidolsang/reservations/:code` — 예약중인 예약 수정. 문의를 뺀 모든 항목을 다시 보낸다.
     완료·취소환불된 예약은 409. 새로 고르는 돌상 컨셉만 삭제 여부를 확인하고, 상태를 조건으로 갱신한다.
   - `POST /admin/choidolsang/reservations/:code/cancel` — 예약 취소(취소환불)
   - `POST /admin/choidolsang/reservations/:code/complete` — 업무 완료
   - 문의 상세 응답에 `reservationCode`(없으면 null)를 싣는다.
   - 달력: `GET /admin/choidolsang/reservations/calendar?from=&to=` — 한국 날짜 [from, to), 최대 62일,
     예약중·완료 예약만 `[{ code, eventAt, eventLocation, customerName, conceptName, status }]` 행사 시각 순
4. 예약 번호는 문의 번호와 같게 둔다. 문의와 예약이 1:1이라 겹치지 않고, 같은 번호로 문의와 예약을 오갈 수 있다.
   고객이 취소 후 다시 예약하면 새 문의를 만든다. 처음에는 따로 무작위 코드를 만들었으나
   마이그레이션 `number_choidolsang_reservations_like_inquiries`로 기존 예약 번호를 문의 번호로 맞췄다.

## 대안 (Alternatives)

1. 잔금을 컬럼으로 저장 — 최종 금액·예약금과 어긋날 수 있어 계산 값으로 둔다.
2. 예약 취소 시 행 삭제 — 매출·환불 기록이 남아야 하므로 상태로 둔다.

## 결과 (Consequences)

- 매출 테이블은 `status = completed`인 예약의 `completedAt`·`totalAmount`를 기준으로 만든다.
- 일정 달력은 `reserved`·`completed` 예약의 `eventAt`을 표시한다. 취소환불 예약은 표시하지 않는다.
- 완료·취소환불된 예약은 수정할 수 없다. 기록으로 남긴다.

## 롤백/재검토 조건

1. 예약금 외에 분할 결제·환불 금액 기록이 필요해질 때
2. 문의 없이 예약을 만들어야 하는 경우가 생길 때
