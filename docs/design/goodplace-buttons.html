버튼과 배지 구분

왼쪽은 지금 모양, 오른쪽은 새 모양. 새 모양은 마우스를 올려 보면 실제 호버도 보인다.

배지 (누를 수 없음)

  • 높이 22px, 12px 글자, 앞에 점
  • 옅은 바탕, 테두리·그림자 없음
  • 모서리 6px, 커서 기본

버튼 (누름)

  • 높이 40px(작은 32px), 모서리 10~12px
  • 채움 또는 1px 선 + 옅은 그림자
  • 호버: 바탕·선·그림자 변화 / 누름: 1px 내려감

칩·세그먼트 (고르기)

  • 칩만 완전한 알약(rounded-full), 그림자 없음
  • 호버: 안쪽 선 + 글자 진해짐
  • 세그먼트는 회색 틀 안, 호버 때 반투명 흰 바탕
